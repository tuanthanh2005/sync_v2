# SyncViet — Database Architecture

## 1. Quy chuẩn chung

- **Hệ quản trị**: MySQL 8.4 (local) / MySQL hoặc MariaDB trên Hostinger/VPS, engine `InnoDB`, charset `utf8mb4`, collation `utf8mb4_unicode_ci`.
- **Múi giờ lưu trữ**: `UTC` trong database (`config/app.php` `'timezone' => 'UTC'`); hiển thị theo `user.timezone` (mặc định `Asia/Ho_Chi_Minh`).
- **Tiền tệ (Phase 3+)**: Lưu dạng số nguyên (`BIGINT` / `UNSIGNED INTEGER`) theo đơn vị nhỏ nhất, tuyệt đối không dùng `FLOAT`/`DOUBLE`.
- **Migrations**: Mọi thay đổi schema quản lý bằng Laravel Migrations (tương thích MySQL/MariaDB và SQLite test).

| `users`                              | Tài khoản thành viên & phân quyền                 | `id`, `name`, `username` (unique, 40), `email` (unique), `role` (`user`/`moderator`/`admin`, indexed), `status` (`active`/`suspended`/`banned`, indexed), `timezone` (default `Asia/Ho_Chi_Minh`), `email_verified_at`, `password` (Argon2id), `two_factor_secret`, `two_factor_recovery_codes`, `two_factor_confirmed_at`, composite index `(status, role)` |

| `jobs`, `job_batches`, `failed_jobs` | Database queue                                    | `queue` (indexed), `payload`, `attempts`, `available_at`                                                                                                                                                                                                                                                                                                     |

## 3. Lộ trình bảng dữ liệu các Phase sau

- **Phase 1 (Social Core)**: `profiles`, `follows`, `user_blocks`, `posts`, `post_media`, `comments`, `post_reactions`, `bookmarks`.
- **Phase 2 (Community & Safety)**: `communities`, `community_members`, `hashtags`, `post_hashtags`, `reports`, `moderation_logs`, `notifications`, `settings`.
- **Phase 3 (Advertising & Monetization)**: `ad_campaigns`, `ad_targets`, `ad_events`, `ad_daily_stats`, `payments` (unique provider reference), `ad_credit_accounts`, `ad_credit_entries` (append-only ledger).
