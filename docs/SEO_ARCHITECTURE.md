# SyncViet SEO Engine V2.0 — System Architecture

## 1. Architectural Philosophy

SyncViet's International SEO & Automatic Organic Growth Engine V2.0 is built directly into the Laravel 13 Modular Monolith (`app/Services/Seo/`), avoiding external microservices, Node SSR daemons, Redis requirements, or Elasticsearch overhead so it runs reliably on **Hostinger Shared Hosting (2 CPU / 3 GB RAM)** and migrates effortlessly to VPS/Cloud infrastructure.

## 3. Event-Driven Async Sync Flow

1. User publishes/updates/deletes a Post, Community, Policy, or Translation.
2. Transaction commits with **zero extra HTTP latency**; `DB::afterCommit()` dispatches `ProcessSeoEntityJob` (`ShouldBeUnique`, bounded retries).
3. Job updates `seo_url_registry`, sets `is_dirty = true` on affected `seo_sitemaps`, and queues deduplicated IndexNow submission when eligible.
4. Hostinger Cron (`php artisan schedule:run`) runs `app:seo:sync` every 5 minutes (`withoutOverlapping()`), rebuilding only dirty sitemap shards atomically and flushing queued IndexNow batches.
