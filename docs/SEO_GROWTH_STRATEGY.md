## 2. Phase 1 Playbook (First 1–1,000 Organic Users)

1. **Seed Evergreen Topic Clusters**: Publish 30–50 genuinely helpful long-form discussions/Q&As across 5–8 focused hashtags (`/topics/{slug}`) in English and Vietnamese first (`>= 300 words`, descriptive titles, authentic media with alt text).
2. **Translate Winners Only**: Monitor **Admin → SEO Center → Overview & Audit** once Search Console syncs real impressions; translate only top-performing evergreen posts into priority markets (`es`, `pt-BR`, `id`, `ja`, `ko`, `fr`, `de`) via the editorial Translation Workflow so every indexed localized page delivers real user value.
3. **Optimize Striking-Distance Queries (Positions 4–20)**: Act on automated `KeywordIntelligenceService` recommendations to refine titles, meta descriptions, and internal topic links without keyword stuffing.
4. **Protect Crawl Budget**: Keep Quality Gate active (`min_post_words >= 12`, `min_topic_posts >= 2`) so short chat-like posts never dilute domain search quality.
