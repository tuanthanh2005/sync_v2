# SEO Security & Privacy Specification

## 1. Threat Model & Mitigations

| Risk                                | Mitigation Implemented                                                                                                                                                                                                                                                                                                                                    |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Host Header Poisoning**           | `SeoConfigService::canonicalBaseUrl()` strictly reads `config('syncviet.seo.canonical_base_url')` (`SEO_CANONICAL_URL` / `APP_URL`), never trusting incoming HTTP `Host` headers for canonicals, hreflang, sitemaps, or robots.txt.                                                                                                                       |
| **Credential Leakage**              | Google Search Console OAuth secrets, refresh tokens, Service Account private keys, and Cloudflare API tokens are encrypted at rest using Laravel `Crypt::encryptString()` (`APP_KEY`), hidden via `#[Hidden]` on `SeoApiConnection`, and NEVER returned in Inertia props, logs, or API responses.                                                         |
| **XSS / Raw JS Injection**          | Controlled GA4 only accepts validated `^G-[A-Z0-9]{6,16}$` IDs; Admin cannot inject arbitrary HTML/JS snippets. JSON-LD uses `JSON_HEX_TAG \| JSON_HEX_AMP \| JSON_HEX_APOS \| JSON_HEX_QUOT`. CSP in `SecurityHeaders` opens `googletagmanager.com` / `google-analytics.com` ONLY when GA4 is actively enabled and NEVER on `/admin/*`.                  |
| **Open Redirects & Redirect Loops** | `RobotsAndRedirectService` enforces `CanonicalUrlService::isSafeRedirectTarget()` (internal paths or canonical host only) and performs 6-hop chain/loop detection before saving any `seo_redirects` rule.                                                                                                                                                 |
| **Private Content & PII Exposure**  | Private/unapproved/deleted posts, draft policies, private profiles, and user emails are strictly excluded from sitemaps, SSR HTML, and JSON-LD. Sensitive routes (`/admin*`, `/wallet*`, `/payments*`, `/messages*`, `/settings*`, `/search?*`) emit `X-Robots-Tag: noindex, nofollow` and `Cache-Control: private, no-cache, no-store, must-revalidate`. |
| **Unauthorized SEO Mutations**      | All `/admin/seo/*` routes enforce `auth`, `verified`, `active`, `admin.2fa`, `can:access-admin`, and granular RBAC middleware (`seo.view`, `seo.manage`, `seo.audit`, `seo.integrations`, `seo.translations`, `seo.redirects`).                                                                                                                           |
| **CSV Formula Injection**           | `SeoUrlsAndSitemapsController::exportRegistryCsv()` neutralizes cells beginning with `=`, `+`, `-`, `@`, tab, or CR.                                                                                                                                                                                                                                      |
| **Organic Funnel Privacy**          | `OrganicGrowthService` hashes daily session IDs (`sha256`) and stores zero raw IP addresses or PII.                                                                                                                                                                                                                                                       |
